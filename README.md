📌 Жоба сипаттамасы

Chat Analyzer — бұл Java тілінде жазылған бағдарлама, чаттағы хабарламалар тізімін талдайды.

Бағдарлама келесі тапсырмаларды орындайды:

Әр қолданушы қанша хабарлама жібергенін анықтайды
Сөздердің қолданылу жиілігін есептейді
Статистиканы ыңғайлы түрде көрсетеді
⚙️ Қалай жұмыс істейді

Әр хабарлама келесі форматта болады:
User: message

Бағдарлама:

Қолданушы мен мәтінді бөледі
Есептеу үшін HashMap қолданады
Сөздер мен қолданушыларды талдайды
🧠 Қолданылған технологиялар
Java
HashMap
Collections Framework
📊 Нәтиже
